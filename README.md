Retail Store Analysis Dashboard (Excel)

 📌 Project Overview
This project focuses on analyzing retail store sales data using Microsoft Excel. The goal is to create an interactive dashboard that provides insights into sales performance, customer behavior, and product trends.


❓ Problem Statement
Retail businesses often deal with large amounts of sales data but lack clear visibility into performance metrics.  
This project aims to transform raw data into a structured and visual dashboard to support better decision-making.


📊 Dashboard Features
- Monthly Sales vs Orders trend analysis  
- Top 10 states by sales  
- Sales distribution by gender (Men vs Women)  
- Order status breakdown (Delivered, Cancelled, Returned)  
- Sales by age group  
- Sales by channel (Amazon, Flipkart, Myntra, etc.)  
- Category-wise sales analysis  
- Interactive filters (Month, Gender, Category)


🛠 Tools & Techniques Used
- Microsoft Excel  
- Pivot Tables  
- Pivot Charts  
- Slicers  
- Data Cleaning & Formatting
- formulas 


📈 Key Insights
- March recorded the highest sales, while November had the lowest  
- Women contribute ~69% of total sales, indicating stronger purchasing behavior  
- Maharashtra, Karnataka, and Uttar Pradesh are top-performing states  
- Adult age group (30–49 years) contributes the highest revenue  
- Amazon, Flipkart, and Myntra dominate sales channels (~80%)  
- Majority of orders (~92%) are successfully delivered
